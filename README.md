# Dustbusters — GitHub Pages Website

This is the finished front-end build for the bright, sales-focused Dustbusters cleaning website. It is a static site and can be published directly with GitHub Pages.

## Publish
1. Create a GitHub repository (for example, `dustbusters`).
2. Upload the **contents of this folder** to the repository root. `index.html` must be in the root, not inside another nested folder.
3. Open **Settings → Pages** in the GitHub repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.

## Required launch edits
The design and sales copy are complete, but the business details were not supplied. Before making the site public:

- Add the real phone number, email address, service area, business hours, and social links where desired.
- Connect the quote form to a form provider such as Formspree, FormSubmit, Basin, or your own backend. GitHub Pages cannot process forms by itself.
- Replace or adjust any service descriptions if Dustbusters does not offer that service.
- Add only real reviews, certifications, insurance claims, guarantees, or years-in-business statements. None were fabricated in this build.
